# ChatAPI 使用手册

面向 ChatAPI 用户的零依赖静态文档站。站点内容基于线上控制台的实际用户流程编写。

## 图片 API 文档

打开 `index.html#images` 查看图片生成、编辑、异步任务、Responses 图片工具、Gemini 原生与批量生图，以及图片理解的调用示例。页面已接入站点目录、搜索和代码复制。接口路径与限制依据项目路由及处理逻辑核对，示例模型是否可用以密钥分组和渠道配置为准。

## 本地预览

直接打开 `index.html`，或在本目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

将本目录完整发布到静态托管服务即可，不需要安装依赖或执行构建命令。入口文件为 `index.html`。
