GET STARTED

五分钟开始

完成账户、额度、密钥和首次请求四个环节。

  1. 1

    登录控制台

    打开 登录页，使用邮箱密码或页面提供的第三方方式登录。

  2. 2

    确认账户余额

    仪表盘右上角和“余额”卡片都会显示可用余额。余额不足时先完成 购买与兑换。

  3. 3

    创建 API 密钥

    进入“API 密钥”，点击“创建密钥”，填写名称并选择能访问目标模型的分组。首次使用可先保留额度、速率和有效期为无限制。

  4. 4

    查询模型并调用

    先请求模型列表，再从响应中选择一个模型发起对话。这样可以避免使用当前分组不支持的模型名。

Terminal
export CHATAPI_BASE_URL="https://chatapi.bwliangc.com/v1"
export CHATAPI_API_KEY="sk-your-api-key"

curl "$CHATAPI_BASE_URL/models" \
  -H "Authorization: Bearer $CHATAPI_API_KEY"
备用域名

主站无法访问时，可将域名替换为 https://chatapis.cc。同一客户端里只保留一个 Base URL。

ACCOUNT

注册与登录

登录成功后会进入仪表盘，看到余额、密钥数量、请求量、消费和性能概览。

邮箱注册

  1. 打开 注册页面。
  2. 填写常用邮箱，并设置至少 6 个字符的密码。
  3. 点击“继续”，系统会向该邮箱发送 6 位验证码。
  4. 输入验证码并点击“验证并创建”。未收到邮件时，等待倒计时结束后可重新发送。
  5. 验证成功后会自动创建账户并进入仪表盘。
收不到验证码

先检查垃圾邮件和邮箱地址是否正确，再使用页面的“重新发送”。验证码输入页失效时，请返回注册页重新开始。

使用 Google 注册或登录

  1. 在注册页或登录页点击“使用 Google 登录”。
  2. 在 Google 授权页选择账号，并确认授权登录 ChatAPI。
  3. 已完成注册和绑定的账号会直接登录并返回仪表盘。
  4. 首次使用该 Google 账号时，按回调页面提示补设密码和确认密码；如果站点要求邀请码，还需填写有效邀请码。
  5. 点击“完成注册”，成功后会自动登录。
确认授权站点

Google 授权前应核对浏览器地址和 ChatAPI 站点信息。不要在非 Google 页面输入 Google 密码，也不要把授权回调地址或验证码发送给他人。

邮箱密码登录

  1. 打开主站，点击“登录”。
  2. 填写注册邮箱和密码后提交。
  3. 进入仪表盘后，先核对右上角账户名与余额。

仪表盘怎么看

区域用途
余额当前可用于调用的账户余额
API 密钥密钥总数与启用数量

Token / 性能输入、输出、缓存 Token，以及 RPM、TPM、平均响应时间
平台拆分按 OpenAI、Anthropic、Gemini、Grok 等平台观察用量
公共设备

不要让浏览器保存密码，使用完成后从右上角用户菜单退出登录。

CREDENTIALS

API 密钥

密钥决定请求可使用的平台、分组与消费边界。

创建密钥

  1. 进入“API 密钥”，点击“创建密钥”。
  2. 填写便于识别的名称，例如 codex-macbook 或 backend-production。
  3. 选择平台，然后选择有可用渠道的分组。
  4. 按需设置安全限制，点击“创建”。
  5. 复制密钥并保存到密码管理器或服务端密钥系统。

创建选项

选项作用建议
平台 / 分组决定可调度的渠道和模型先在“渠道状态”确认可用模型
自定义密钥自行指定密钥字符串至少 16 位，仅字母、数字、下划线和连字符
IP 限制设置白名单或黑名单，支持 IP/CIDR固定出口 IP 的生产服务建议启用
额度限制限制该密钥可消费的最大 USD 金额为测试、CI 或共享项目设置上限
速率限制设置 5 小时、1 天、7 天消费窗口防止异常流量持续消耗
有效期7/30/90 天或自定义过期时间临时项目使用短期密钥

日常管理

密钥列表支持搜索、分组和状态筛选。你可以复制、启用、停用、修改分组、重置额度用量或删除密钥。删除操作不可撤销，轮换密钥时应先部署新密钥并验证，再停用旧密钥。

平台必须匹配

Codex 和 OpenAI SDK 通常选择 OpenAI 平台；Claude Code 通常选择可提供 Messages API 的平台。可用选项以账户实际分组为准。

OPENAI COMPATIBLE

API 调用

使用 Bearer Token 认证，并优先从 /v1/models 获取当前可用模型。

基础信息

API 根地址https://chatapi.bwliangc.com/v1
备用根地址https://chatapis.cc/v1
认证请求头Authorization: Bearer sk-your-api-key
常用端点GET /models、POST /responses、POST /chat/completions、POST /messages

Responses API

cURL
curl "https://chatapi.bwliangc.com/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": "用一句话解释什么是幂等性"
  }'

OpenAI Python SDK

Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CHATAPI_API_KEY"],
    base_url="https://chatapi.bwliangc.com/v1",
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input="用一句话解释什么是幂等性",
)
print(response.output_text)

OpenAI JavaScript SDK

JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.CHATAPI_API_KEY,
  baseURL: "https://chatapi.bwliangc.com/v1",
});

const response = await client.responses.create({
  model: "gpt-5.6-terra",
  input: "用一句话解释什么是幂等性",
});

console.log(response.output_text);
模型名会变化

示例模型用于说明请求格式。实际调用前请查询 /v1/models 或在“渠道状态”确认当前分组支持的模型。

CC-SWITCH

CC-Switch 配置

从 ChatAPI 一键导入供应商，无需手动编辑 Codex 配置文件。

安装 CC-Switch

CC-Switch 是跨平台的 AI 编程工具供应商管理应用，支持 Codex、Claude Code 和 Gemini CLI 等客户端。

系统安装方式
macOS 12+运行 brew install --cask cc-switch，或从 Releases 下载 DMG
Windows 10+从 Releases 下载 MSI 或 Portable ZIP
Linux从 Releases 选择适合发行版的安装包

首次启动时允许应用注册 ccswitch:// 协议；ChatAPI 的一键导入依赖该协议唤起 CC-Switch。

安装目标客户端

CC-Switch 不包含 AI 客户端

CC-Switch 负责管理和切换供应商配置。使用前仍需单独安装目标客户端；ChatAPI 当前一键导入支持 Codex CLI、Codex Desktop、Claude Code 和 Gemini CLI。

从 ChatAPI 一键导入

  1. 1

    准备密钥

    在 ChatAPI“API 密钥”页面创建密钥，平台和分组需与目标客户端匹配，并确认分组存在可用渠道。

  2. 2

    打开导入窗口

    在该密钥的操作列点击“导入到 CCS”。如果没有此按钮，可能是站点暂时隐藏了 CCS 导入功能。

  3. 3

    选择应用和模型

    按用途选择 Codex、Claude Code 或 Gemini CLI，再选择当前分组实际支持的主模型。Claude Code 还可按需设置 Haiku、Sonnet 和 Opus 模型映射。

  4. 4

    确认导入

    点击“导入”。系统询问是否打开 CC-Switch 时选择允许，再核对供应商名称、端点、模型和密钥后确认。

  5. 5

    启用供应商

    在 CC-Switch 对应客户端页面选中刚导入的 ChatAPI 供应商并点击“启用”，然后完全退出并重新启动目标客户端。

导入内容

项目ChatAPI 自动填写
应用OpenAI 平台密钥默认选择 Codex，也可在导入窗口切换
供应商名称、ChatAPI 首页与 API 端点
认证当前 API 密钥
模型导入窗口选择的主模型
用量查询启用余额查询，默认每 30 分钟自动更新

手动添加备用方案

深度链接无法使用时，可在 CC-Switch 点击“添加供应商”，为 Codex 创建自定义供应商：

名称ChatAPI
API 地址https://chatapi.bwliangc.com
API Key粘贴自己的 ChatAPI 密钥
模型填写当前分组支持的模型 ID

保存后选中该供应商并点击“启用”。若主站连接失败，可将 API 地址换为 https://chatapis.cc。

深度链接包含 API Key

ChatAPI 生成的 ccswitch:// 链接会携带当前密钥。只在自己的设备上完成导入，不要复制、分享或发布该链接；导入确认页也应再次核对来源。

PLAYGROUND

在线测试

无需写代码即可验证密钥、模型和图片输入是否可用。

发起测试

  1. 先创建并启用一个 API 密钥。
  2. 进入“在线测试”，选择密钥。
  3. 刷新并选择模型，或输入模型名。
  4. 输入消息，按需添加图片，然后发送。

适合排查什么

  • 密钥是否启用并已分配分组。
  • 模型是否在当前分组可用。
  • 图片输入是否受模型支持。
  • 问题来自平台配置还是本地 SDK/网络环境。
隐私说明

控制台说明聊天记录不做存储，数据仅用于透传上游。仍不要在测试中发送密码、密钥、身份证件或其他不必要的敏感数据。

OBSERVABILITY

用量与账单

从总览定位趋势，再下钻到单次请求。

用量总览

“使用记录”顶部汇总所选时间范围内的请求数、输入/输出/缓存 Token、实际消费、标准消费和平均耗时。图表可按 Token 或实际消费查看模型、分组与端点分布。

筛选与明细

可按 API 密钥、模型、分组、类型、计费类型和计费模式筛选。明细表包含推理强度、端点、IP、Token、费用、延迟和时间；列设置可隐藏暂时不关心的字段。

导出与错误请求

  • 点击“导出 CSV”保留筛选后的账单明细。
  • 切换“错误请求”查看失败调用，结合状态码和时间定位问题。
  • 比较“实际”与“标准”费用时，应同时考虑渠道倍率、缓存 Token 和计费模式。
时间范围会影响总数

仪表盘“总计”和使用记录默认时间范围可能不同。对账前先统一时间范围、时区和筛选条件。

BALANCE

购买与兑换

通过控制台的 CDK 购买入口获得兑换码，再回到“兑换”页面入账。

购买 CDK

  1. 登录后点击侧栏“CDK 购买”。
  2. 在官方购买页面确认商品、金额和支付信息。
  3. 支付完成后取得兑换码。
  4. 回到 ChatAPI 控制台，不要把兑换码发给他人。

兑换

  1. 进入“兑换”，确认当前余额与并发数。
  2. 原样粘贴兑换码；兑换码区分大小写。
  3. 点击“兑换”，等待余额、并发数或试用权限更新。
  4. 在“最近活动”核对变更类型、时间和金额。
兑换码规则

每个兑换码只能使用一次，可能增加余额、并发数或试用权限。成功后额度即时更新。

CONSOLE

其他功能

渠道状态、邀请返利和排行榜都可从用户侧栏进入。

渠道状态

按渠道或模型搜索，查看渠道平台、可访问分组和支持模型。创建密钥前先在这里确认目标模型，能减少“模型不存在”或分组不匹配。

邀请返利

页面提供邀请码和邀请链接。被邀请用户充值后，邀请人按页面显示比例获得返利额度；可用返利可转入账户余额。比例和规则以页面实时显示为准。

消费排行榜

榜单按消费金额实时排名，并提供今日实时与昨日结算两个视图。奖池、参与门槛、奖励名额和分配比例会显示在榜单顶部，以当日规则为准。

SECURITY

安全设置

把每个密钥的权限和影响范围控制在完成任务所需的最小范围。

推荐基线

  • 为不同设备、应用和环境创建独立密钥。
  • 生产密钥配置固定出口 IP 白名单。
  • 测试和 CI 密钥设置额度、速率和有效期。
  • 密钥写入环境变量或密钥管理服务，不进入前端代码。
  • 发现泄露时立即停用旧密钥，创建并部署新密钥。

个人设置

“个人资料”支持修改用户名、头像和密码，管理邮箱及第三方登录绑定，配置余额不足邮件提醒。两步验证是否可用由站点管理员配置。

余额提醒

启用余额不足提醒并填写已验证邮箱。自定义阈值留空时使用系统默认值；生产业务建议设置能覆盖正常补充周期的阈值。

TROUBLESHOOTING

常见问题

先看状态码，再核对密钥、分组、模型和额度。

401认证失败或密钥无效

确认使用 Authorization: Bearer ...，没有多余引号或空格；再到密钥列表检查密钥是否启用、过期或已删除。

403分组、IP 或权限不允许

检查密钥分组与目标平台是否匹配；若设置了 IP 白名单，确认请求实际出口 IP 已包含在规则中。

404端点或模型不存在

OpenAI 兼容根地址通常应包含 /v1。先调用 GET /v1/models，使用返回的模型 ID，不要依赖旧配置中的模型名。

429消费窗口、并发或上游限流

检查密钥的 5 小时、1 天和 7 天消费限制，以及账户并发数。短暂上游限流可退避重试，持续失败应查看“错误请求”。

余额余额充足但仍无法调用

账户余额只是条件之一。还需确认密钥额度未耗尽、密钥未过期、分组有可用渠道、模型受支持且 IP 规则允许。

CCS导入后 Codex 没有生效

确认已在 CC-Switch 的 Codex 页面选中 ChatAPI 并点击“启用”，然后完全退出并重启 Codex。若导入链接没有唤起应用，请重新安装 CC-Switch，确认系统已注册 ccswitch:// 协议。

网络主站连接失败

将客户端 Base URL 切换到 https://chatapis.cc 后重试。不要同时拼接两个域名，也不要重复添加 /v1/v1。
